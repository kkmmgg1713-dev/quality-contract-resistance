# 품질·계약저항 조회

스마트폰에서 업체별 품질등급과 계약저항을 확인하는 내부 업무용 PWA입니다. 별도 서버나 데이터베이스 없이 정적 파일만으로 실행되며, 설치 후 오프라인에서도 조회할 수 있습니다.

## 포함 기능

- 업체명 일부·초성 검색으로 2025·2024 품질등급 조회
- PDF의 업체명·품목명 및 신규납품·평가 미시행 표기 반영
- 업체·연도·품목·규격별 2025·2026 계약저항 및 계약번호 조회
- 도체저항 측정기 설정 안내 이미지 열람
- 일진홀딩스와 일진전기 별도 구분
- 규격저항 제외
- 모바일 홈 화면 설치 및 오프라인 조회
- GitHub Pages 하위 경로 지원

## 매우 중요한 보안 주의

2025년 계약저항 원본은 외부 공개 불가 입찰정보로 명시되어 있습니다. 이 폴더의 `data.js`에 계약저항이 포함되어 있으므로 **공개 GitHub 저장소나 누구나 접속할 수 있는 GitHub Pages에 올리면 안 됩니다.**

비공개 저장소를 사용하고, Pages 사이트의 접근 권한도 반드시 내부 사용자로 제한하십시오. 사용 중인 GitHub 요금제에서 비공개 Pages 접근 제한을 제공하지 않는다면 GitHub Pages 대신 사내 인증이 적용된 호스팅이나 오프라인 설치 방식을 사용해야 합니다.

`robots.txt`와 검색엔진 차단 메타 태그가 포함되어 있지만 이는 보안 기능이 아니며 URL 직접 접근을 막지 못합니다.

## GitHub 업로드

1. GitHub에서 비공개 저장소를 새로 만듭니다.
2. 이 폴더 안의 파일을 모두 저장소 최상위에 업로드합니다.
3. 저장소의 Pages 설정에서 배포 브랜치와 루트 폴더를 선택합니다.
4. 배포 후 사이트 접근 권한이 내부 사용자로 제한되는지 확인합니다.

## 스마트폰 설치

- Android Chrome: 사이트 접속 후 메뉴에서 **앱 설치** 또는 **홈 화면에 추가**를 선택합니다.
- iPhone Safari: 공유 버튼을 누르고 **홈 화면에 추가**를 선택합니다.
- 처음 한 번 온라인에서 열어야 오프라인용 파일이 저장됩니다.

## 데이터 수정

앱 데이터는 `data.js`에 들어 있습니다. 데이터 변경 후 `sw.js`의 `CACHE_NAME` 버전을 올리면 기존 설치 기기에도 새 파일이 갱신됩니다.
